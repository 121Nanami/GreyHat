# GreyHat

Consumer protection tools and small open-source utilities.

GreyHat ships defensive, consumer-facing helpers (privacy, phishing awareness, safer defaults) plus a catalog of lightweight utility apps. Work stays non-malicious: no malware, exploits, or unauthorized access.

## Tools

- **[urlguard](tools/urlguard/)** — offline URL safety checker (heuristics for phishing / lookalikes). Candidate for BlackArch packaging; see `tools/urlguard/SUBMIT.md`.

## Apps

Utility apps live under [`apps/`](apps/). Full catalog: [`apps/CATALOG.md`](apps/CATALOG.md).
