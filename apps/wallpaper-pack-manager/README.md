# Wallpaper Pack Manager

Stub CLI for managing themed wallpaper packs on a custom spin. Tracks install state in a JSON cache — does not download or copy image files yet.

## Run

```bash
python3 wallpaper_pack_manager.py list
python3 wallpaper_pack_manager.py install ellen-deep-sea
python3 wallpaper_pack_manager.py status
python3 wallpaper_pack_manager.py remove ellen-deep-sea
```
